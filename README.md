# 跑步轨迹记录器

把一串经纬度变成「总距离 + 平均配速 + 一张路线图」的小工具。用来记录**自己真实跑过的路**。

## 这是什么

每次跑完，把手表或手机记下的几个坐标点（纬度、经度）填进脚本，它就会算出：

- 总距离（公里）
- 总时长与平均配速（分'秒"/公里）
- 一张 SVG 路线图，用浏览器直接打开

## 怎么跑

```powershell
python D:\learn\12-run-tracker\run_tracker.py
start D:\learn\12-run-tracker\route.svg
```

换数据只改文件顶部两处：`POINTS`（点列表）和 `MINUTES / SECONDS`（时长）。

## 现在的输出

- 点数 5（4 段）、总距离 **0.532 公里**
- 总时长 320 秒（5 分 20 秒）、平均配速 **10'01"/公里**
- 路线图 `route.svg`（另有换数据版 `route_circle.svg`）

## 文件说明

| 文件 | 作用 |
|---|---|
| `distance.py` | 只算两点距离，用来验证公式（天安门→外滩 1067.8 公里） |
| `total_distance.py` | 一串点 → 总距离（相邻两点累加） |
| `pace.py` | 时长 + 距离 → 配速，并能回算验证 |
| `make_svg.py` | 经纬度 → 画布坐标 → 生成 SVG |
| `run_tracker.py` | v1 合并版：一次跑完距离、配速、路线图 |

## 我学到什么

- **球面距离**：经纬度是角度，两点距离要用 Haversine 公式（公式查文档就行，不用背）
- **累加才是总距离**：`for i in range(len(points)-1)` 配对相邻两点，一段段加起来
- **配速 = 总秒数 ÷ 公里数**，再用 `divmod` 拆成「分、秒」
- **Python 不画图**：它写一段 SVG 文本（`points="40,440 40,340"`），浏览器照文本渲染
- **函数分工**：算距离、算配速、画图各一个函数，`main()` 只负责按顺序调用
